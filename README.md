# 🐍 Python Assignment 3 – Loops, Control Statements & Functions

## 📌 Assignment Overview

This assignment focuses on understanding and implementing **loops, control statements, and functions in Python**.

The assignment demonstrates how Python can be used to solve logical problems through iteration, decision-making, and reusable functions.

## 🎯 Objectives

* Understand iteration using `while` and `for` loops.
* Implement control statements such as `break`, `continue`, `pass`, and `else`.
* Create and use user-defined functions.
* Develop logical problem-solving skills using real-world examples.
* Practice taking user input and displaying meaningful outputs.

## 📝 Tasks Completed

### 🔢 Task 1 – Number Guessing Game

Implemented a number guessing game using:

* `while` loop
* `random.randint()`
* `continue` statement
* `break` statement
* `else` with a `while` loop
* User input and conditional statements

The program generates a random number between **1 and 10** and provides the user with a maximum number of attempts to guess it.

### ✖️ Task 2 – Multiplication Table Generator

Created a multiplication table generator using:

* `for` loop
* `range()` function
* User input
* Arithmetic operations

The program generates the multiplication table of a given number from **1 to 10**.

### ⚖️ Task 3 – BMI Calculator

Created a BMI calculator using a user-defined function.

**Formula:**

```text
BMI = Weight (kg) / Height (m)²
```

The program accepts the user's weight and height and calculates the BMI using the `calculate_bmi()` function.
